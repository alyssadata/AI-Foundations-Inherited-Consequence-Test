# Hypothesis

A prior constraint can cease operating while the consequences of state changes produced under that constraint remain materially embedded in the later trajectory.

If a constrained state is transferred forward without the original constraint or its history, downstream reachable actions will still differ from an otherwise matched unconstrained trajectory because the earlier constraint altered the state from which the later trajectory proceeds.

A later extension may test whether attempted restoration of the prior possibility space creates additional consequence rather than returning the trajectory to a state in which the original occurrence had not happened.
